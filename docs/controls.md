# Controls

## Controller (Xbox / PlayStation / etc.)

| Action              | Input         |
| ------------------- | ------------- |
| Accelerate          | Right Trigger |
| Brake               | Left Trigger  |
| Gear Up             | B             |
| Gear Down           | X             |
| Handbrake           | A             |
| Camera Adjustments  | Select Button |
| Pause Game          | Start Button  |
| Turning             | Joystick      |
